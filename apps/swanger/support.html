Common questions

My spec references external files and the diagram doesn't show.
Swanger runs in the App Store sandbox, which only supports single-file specs. Specs that reference external files with $ref are not currently supported.

The diagram doesn't match what I expect from my schema.
The diagram shows what the spec says in a simplified visual form. For exact validation, use the Try it tab — it runs a full JSON Schema validator and explains any mismatches in plain English.
